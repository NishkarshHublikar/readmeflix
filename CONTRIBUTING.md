# 🤝 Contributing to ReadmeFlix

Thank you for considering contributing to ReadmeFlix!

We welcome:
- Bug fixes
- Feature improvements
- Documentation updates
- UI/UX enhancements
- CLI improvements

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/NishkarshHublikar/readmeflix.git
```

Install dependencies:

```bash
npm install
```

Run development mode:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```

- Keep commits meaningful
