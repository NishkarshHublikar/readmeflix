## 📦 Installation

```bash
npm install -g readmeflix
```

---

## 🚀 Usage

### Analyze Repository

```bash
readmeflix analyze
```

### Generate README

```bash
readmeflix generate --theme netflix
```

```bash
readmeflix generate --theme glass
```

```bash
readmeflix generate --theme minimal
```

### Score README Quality

```bash
readmeflix score
```

---

## 🎨 Available Themes

| Theme | Description |
|---|---|
| minimal | Clean and simple |
| netflix | Cinematic dark README |
| glass | Modern developer aesthetic |

## 📊 README Scoring

ReadmeFlix intelligently scores your README quality.

Checks include:

- Installation section
- Usage section
- Screenshots
- Tech stack
- Contributing guide
- API documentation
- License section
